# Code Security Scan

A CLI tool that scans repositories for security vulnerabilities and suggests one-click fixes.

## Installation

```bash
pip install -e .
```

## Usage

```bash
code-security-scan <repo_path>
```

## Contributing

1. Clone the repository
2. Create a virtual environment
3. Install dependencies
4. Run tests
5. Make changes and add tests
6. Submit a pull request
